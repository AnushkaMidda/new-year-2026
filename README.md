# New Year 2026 🌙

A minimalist New Year 2026 web experience exploring reflection, silence, and unspoken confessions.

## ✨ About the Project
This project is designed as a calm, poetic transition into the new year.  
It focuses on emotions we carry quietly — growth, healing, and things left unsaid.

The website includes:
- A welcoming New Year landing page
- A confessions page displaying reflective thoughts
- Smooth transitions, subtle animations, and a minimalist aesthetic

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
